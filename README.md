# IBM - Implementing the Application Front End Using React Components (FinLogger)

FinLogger is a React-based expense tracking application developed as part of the IBM SkillsBuild capstone project **“Implementing the Application Front End Using React Components.”**

The application provides an interface for viewing expense summaries, exploring expense details, and managing expense-related information.

## Features

- **Expense Overview:** View a summary of expenses and income.
- **Expense Summary:** Explore expenses across different categories.
- **Expense Details:** View individual expense records.
- **Month Selection:** Navigate expenses by month.
- **Expense Management:** Add, edit, and delete expenses through the application interface.
- **Responsive UI:** Built using React and React Bootstrap components.

## Technologies Used

- React.js
- JavaScript
- React Bootstrap
- HTML5
- CSS3

## Learning Outcomes

- Building reusable React components.
- Passing data through props.
- Managing shared application state using React Context.
- Using React Hooks, including `useState`, `useEffect`, and `useContext`.
- Creating user interfaces with React Bootstrap.
- Organizing a React application into reusable modules.

This project was completed as part of the IBM SkillsBuild React capstone learning activity.
